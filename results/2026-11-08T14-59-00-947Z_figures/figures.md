- `overview-latency-mean-ms.pdf`: Mean event latency per run in Block~1. Points show the median of the paired differences $A - B$, bars its 95\% percentile bootstrap interval, which holds per test, is not Holm-corrected and is no significance decision. Filled points are significant in the Wilcoxon signed-rank test after Holm correction over 39~tests ($\alpha = 0.05$). Rings mark a different sign test decision. Interval and test differ for comparison~1 at 50~clients and comparison~5 at 500~clients. Widest interval per column 0.12, 0.10 and 0.49~ms.
- `overview-cpu-seconds-total.pdf`: CPU time per run (variant and Redis) in Block~1. Points show the median of the paired differences $A - B$, bars its 95\% percentile bootstrap interval, which holds per test, is not Holm-corrected and is no significance decision. Filled points are significant in the Wilcoxon signed-rank test after Holm correction over 39~tests ($\alpha = 0.05$). Rings mark a different sign test decision. Interval and test differ for comparison~5 at 500~clients. Widest interval per column 0.007, 0.012 and 0.099~s.
- `overview-working-set-peak-bytes-total.pdf`: Peak working set (variant and Redis) in Block~1. Points show the median of the paired differences $A - B$, bars its 95\% percentile bootstrap interval, which holds per test, is not Holm-corrected and is no significance decision. Filled points are significant in the Wilcoxon signed-rank test after Holm correction over 39~tests ($\alpha = 0.05$). Widest interval per column 5.8, 4.9 and 6.3~MiB.
- `overview-connect-mean-ms.pdf`: Mean connection setup time per run in Block~1. Points show the median of the paired differences $A - B$, bars its 95\% percentile bootstrap interval, which holds per test, is not Holm-corrected and is no significance decision. Filled points are significant in the Wilcoxon signed-rank test after Holm correction over 39~tests ($\alpha = 0.05$). Rings mark a different sign test decision. Interval and test differ for comparison~1 at 10~clients and comparison~5 at 10~clients. Widest interval per column 0.20, 0.13 and 0.05~ms.
- `spread-working-set-peak-bytes-total.pdf`: Spread of the peak working set (variant and Redis) in Block~1.
